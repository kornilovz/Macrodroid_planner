# Расписание событий для MacroDroid

Готовая конфигурация для Android. Она показывает недельное расписание, добавляет и удаляет записи, переводит время между UTC и местным часовым поясом, импортирует расписание из сообщения и запускает звуковое уведомление перед событием.

Программирование и root-права не нужны.

## Сначала скачайте файл

Учётная запись GitHub не нужна. Устанавливать GitHub или Git тоже не нужно.

Нажмите эту ссылку:

### [Скачать готовую конфигурацию (.mdr)](./MacroDroid_planner.mdr?raw=1)

Если файл не скачался автоматически:

1. Нажмите в списке файлов **MacroDroid_planner.mdr**.
2. На открывшейся странице нажмите значок стрелки вниз **Download raw file**. На телефоне он может находиться в меню с тремя точками.
3. Найдите файл в папке **Загрузки** или **Download**.

Зелёная кнопка **Code**, скачивание ZIP и регистрация на GitHub не нужны.

Имя скачанного файла должно заканчиваться на `.mdr`. Если браузер добавил `.txt`, переименуйте файл и удалите только окончание `.txt`.

## 1. Установите MacroDroid

Рекомендуемый источник:

- [MacroDroid в Google Play](https://play.google.com/store/apps/details?id=com.arlosoft.macrodroid)

Если Google Play недоступен:

- [Тема MacroDroid на 4PDA](https://4pda.to/forum/index.php?showtopic=374521)

На 4PDA для скачивания вложений может потребоваться регистрация. Используйте обычную актуальную версию приложения. Модифицированные APK устанавливайте только на свой риск.

Для установки APK с 4PDA Android может запросить разрешение **«Установка неизвестных приложений»**:

1. Разрешите установку для браузера или файлового менеджера, через который открыт APK.
2. Установите MacroDroid.
3. После установки снова запретите этому приложению установку неизвестных программ.

## 2. Выдайте нужные разрешения

Названия пунктов немного отличаются у Samsung, Xiaomi, Realme и других производителей.

### Уведомления

При первом запуске разрешите MacroDroid показывать уведомления.

Если запрос не появился:

**Настройки Android → Приложения → MacroDroid → Уведомления → Разрешить**.

### Работа в фоне

Отключите оптимизацию батареи для MacroDroid. Иначе Android может остановить планировщик, и событие не сработает вовремя.

Обычный путь:

**Настройки Android → Приложения → MacroDroid → Батарея → Без ограничений**.

Пункт также может называться **«Не оптимизировать»**, **«Не ограничивать»** или **«Разрешить работу в фоне»**.

На Xiaomi, Huawei, Honor, Realme и похожих прошивках дополнительно разрешите автозапуск MacroDroid.

### Отображение поверх других приложений

Это разрешение нужно для меню редактора, открываемого из шторки.

Обычный путь:

**Настройки Android → Приложения → Специальный доступ → Поверх других приложений → MacroDroid → Разрешить**.

### Что не требуется

Эта конфигурация не требует:

- root-прав;
- ADB-команд;
- MacroDroid Helper;
- доступа к контактам, SMS, геолокации или микрофону;
- чтения уведомлений других приложений;
- службы специальных возможностей, если Android сам не запросил её для показа меню или доступа к буферу обмена.

Не выдавайте лишние разрешения без понятной причины.

## 3. Импортируйте конфигурацию

Если файл ещё не скачан, используйте ссылку **«Скачать готовую конфигурацию»** в начале этой инструкции.

> **Важно:** файл `.mdr` — полный экспорт MacroDroid. Его импорт может заменить существующие макросы, переменные и часть настроек. На новой установке это безопасно. Если MacroDroid уже используется, сначала откройте **Экспорт/импорт** и сохраните резервную копию.

Импорт:

1. Откройте MacroDroid.
2. На главном экране нажмите **Экспорт/импорт**.
3. В разделе импорта выберите **Хранилище** или **Локальный файл**.
4. Выберите скачанный файл `.mdr`.
5. Подтвердите импорт.
6. Откройте вкладку **Макросы** и проверьте, что включены три макроса:
   - **Редактор расписания**;
   - **Планировщик UTC**;
   - **Уведомление UTC**.

Можно также открыть файл `.mdr` из файлового менеджера и выбрать MacroDroid. Этот способ работает не на всех прошивках.

## 4. Добавьте кнопку редактора в шторку

1. Дважды проведите вниз от верхнего края экрана.
2. Нажмите **Изменить**, значок карандаша или меню с тремя точками.
3. Найдите плитку MacroDroid. Она может называться **«Редактор — Расписание»** или **«MacroDroid Tile 1»**.
4. Перетащите плитку в активную часть панели.
5. Нажмите плитку. Откроется меню расписания.

Если плитки нет, перезапустите MacroDroid и снова откройте редактор панели быстрых настроек.

## 5. Импортируйте расписание

Чистая конфигурация не содержит записей и видов событий. Получите отдельное сообщение с расписанием от его автора.

1. Выделите и скопируйте сообщение целиком. Не удаляйте строки `MDUTC-BEGIN` и `MDUTC-END`.
2. Сразу нажмите плитку **Редактор — Расписание**.
3. Выберите **Импорт расписания**.
4. MacroDroid прочитает текст из буфера обмена.
5. Дождитесь сообщения **«Расписание импортировано»**.

Виды событий создаются автоматически из импортированных записей. После этого работает пункт **«Добавить событие»**.

## 6. Проверьте работу

1. Откройте редактор из шторки.
2. Выберите **Показать расписание**.
3. Выберите **Местное время**.
4. Проверьте записи и строку с временем до следующего события.

Время внутри конфигурации хранится в UTC. При показе местного времени используется текущий часовой пояс телефона.

## Меню редактора

- **Показать расписание** — показывает записи в UTC или местном времени.
- **Добавить событие** — добавляет запись.
- **Удалить событие** — удаляет выбранную запись.
- **Поделиться расписанием** — создаёт переносимый текст для другого телефона.
- **Импорт расписания** — загружает расписание из буфера обмена.

## Настройте уведомления под себя

За оповещение отвечает только макрос **«Уведомление UTC»**. Не добавляйте пользовательские ограничения в **«Планировщик UTC»**: планировщик может перестать рассчитывать следующее событие.

Откройте:

**MacroDroid → Макросы → Уведомление UTC**.

Сейчас макрос выполняет два действия:

1. **Воспроизвести звук** — подаёт звуковой сигнал.
2. **Всплывающее сообщение** — показывает название текущего события.

Ненужное действие можно отключить переключателем или удалить. После изменений нажмите значок сохранения.

### Получать только выбранные события

Название текущего события хранится в глобальной переменной **«Текущее событие»**.

Чтобы получать только один вид событий:

1. Прокрутите макрос **«Уведомление UTC»** до нижнего раздела **«Ограничения»**.
2. Нажмите **«+»**.
3. Выберите ограничение **«Переменная MacroDroid»**.
4. Выберите переменную **«Текущее событие»**.
5. Выберите сравнение строк **«Равно»**.
6. Введите название события точно так же, как в расписании.

Чтобы исключить один вид событий, выберите **«Не равно»**.

Чтобы разрешить несколько видов, объедините проверки **«Равно»** в группу **ИЛИ**. Не добавляйте несколько отдельных проверок «Равно» подряд: обычные ограничения соединяются условием **И**, поэтому событие не сможет иметь несколько названий одновременно.

### Полезные ограничения для всего уведомления

Добавляйте их в нижний раздел **«Ограничения»** макроса **«Уведомление UTC»**:

- **Время суток** — получать оповещения только днём или только ночью.
- **День недели** — отключить оповещения в выходные или рабочие дни.
- **Подключение к Wi-Fi** — работать только дома, на работе или вне выбранной сети.
- **Местоположение** — работать только в выбранном месте.
- **Экран включён/выключен** — не показывать сообщение при активном использовании телефона.
- **Устройство заблокировано/разблокировано** — ограничить оповещения состоянием блокировки.
- **Режим «Не беспокоить»** — не оповещать во время тихого режима.
- **Уровень заряда** или **питание подключено** — не тратить заряд при низком уровне батареи.

Все ограничения в нижнем разделе управляют сразу звуком и сообщением. Если хотя бы одно обязательное ограничение не выполнено, макрос ничего не покажет и не воспроизведёт.

В конфигурации может отображаться отключённый пример ограничения времени **20:30–07:30**. Серое отключённое ограничение ни на что не влияет. Не включайте его без проверки: при включении оно разрешит макрос только в указанном интервале.

### Ограничить только звук

Если сообщение нужно всегда, а звук — только при определённых условиях, добавьте ограничение к действию **«Воспроизвести звук»**, а не ко всему макросу.

Примеры:

- воспроизводить звук только днём;
- воспроизводить звук только в наушниках;
- не воспроизводить звук в режиме «Не беспокоить»;
- воспроизводить звук только при выключенном экране.

Точный пункт для ограничения отдельного действия зависит от версии MacroDroid: нажмите или удерживайте действие **«Воспроизвести звук»**, затем выберите **«Добавить ограничение»**.

### Добавить обычное уведомление Android

Всплывающее сообщение быстро исчезает. Чтобы событие оставалось в шторке:

1. В макросе **«Уведомление UTC»** нажмите **«+»** в разделе действий.
2. Найдите действие **«Показать уведомление»**.
3. В заголовке напишите, например, `Расписание`.
4. В текст вставьте специальный текст переменной **«Текущее событие»**.
5. Сохраните макрос и разрешите уведомления MacroDroid в настройках Android.

Можно также добавить вибрацию или произнесение текста. Для произнесения учитывайте окружающих: название события будет сказано вслух.

## Интересные действия для разных событий

Макрос **«Уведомление UTC»** может не только подавать сигнал. В момент события он может открыть приложение, показать анимацию, изменить яркость, включить вибрацию или выполнить цепочку действий.

Название события доступно через переменную **«Текущее событие»**. Поэтому для `Игра`, `Тренировка`, `Чтение` и других видов можно настроить разное поведение.

Эти возможности не включены в готовую конфигурацию. Некоторые дополнительные действия запросят новые разрешения. Выдавайте их только для выбранного действия.

### Как выполнить действие только для одного вида события

Для одного действия добавьте к нему ограничение:

**Переменная MacroDroid → Текущее событие → Равно → название события**.

Для нескольких последовательных действий удобнее использовать блок:

1. Добавьте действие **«Условие If»**.
2. Условие: **«Текущее событие» равно нужному названию**.
3. Поместите действия внутрь блока.
4. Завершите блок действием **End If**.

Название вводите точно как в расписании, включая пробелы и регистр букв.

### Радужная подсветка экрана

Для подсветки краёв найдите действие **Edge Notification Light**. В русской версии название может выглядеть как **«Боковая подсветка уведомлений»**.

Пример:

1. Откройте **«Уведомление UTC»**.
2. Нажмите **«+»** в разделе действий.
3. Найдите по поиску `Edge Notification Light` или слово `подсветка`.
4. Выберите показ подсветки.
5. Настройте цвета, толщину, скорость и автоматическое скрытие, если эти параметры доступны на телефоне.
6. Добавьте ограничение по переменной **«Текущее событие»**.

Для настоящего радужного перелива используйте действие **Animation Overlay**:

1. Скачайте Lottie-анимацию радуги в формате JSON из доверенного источника.
2. Добавьте действие **Animation Overlay**.
3. Выберите скачанный JSON-файл.
4. Настройте размер и положение анимации.
5. Настройте длительность и сначала проверьте анимацию вручную.

Анимация накладывается поверх экрана и требует разрешения **«Поверх других приложений»**. На заблокированном экране результат зависит от модели телефона и прошивки.

Фонарик телефона обычно умеет светить только одним цветом. Радужный эффект создаётся экраном или подсветкой краёв, а не вспышкой камеры.

Документация: [Animation Overlay](https://macrodroidforum.com/wiki/index.php/Action%3A_Animation_Overlay), [список действий MacroDroid](https://www.macrodroidforum.com/wiki/index.php/Actions).

### Свернуть текущее приложение и открыть игру

Android не разрешает обычному приложению безопасно закрыть все остальные приложения. Штатное действие **Launch Home Screen** работает как кнопка «Домой»: текущее приложение остаётся в памяти, но уходит с экрана.

Безопасная последовательность:

1. **Launch Home Screen** — перейти на главный экран.
2. **Wait Before Next Action** — подождать `300–500 мс`.
3. **Launch Application** — выбрать нужную игру.

В большинстве случаев достаточно одного действия **Launch Application**: Android сам откроет игру поверх текущего приложения.

Чтобы игра не открылась неожиданно:

- добавьте **Confirm Next** перед запуском;
- добавьте ограничение **«Устройство разблокировано»**;
- при необходимости добавьте ограничение **«Экран включён»**;
- ограничьте блок нужным видом события.

Не используйте **Kill Application** или очистку процессов без необходимости. Эти действия могут требовать специальных прав и приводить к потере несохранённых данных.

Документация: [Launch Home Screen](https://macrodroidforum.com/wiki/index.php/Action%3A_Launch_Home_Screen), [Launch Application](https://www.macrodroidforum.com/wiki/index.php/Action%3A_Launch_Application).

### Открыть Telegram

Чтобы открыть главный экран Telegram:

1. Добавьте действие **Launch Application**.
2. Выберите Telegram.
3. Добавьте ограничение по виду события, например `Telegram`.

Чтобы открыть публичный чат, пользователя или канал:

1. Добавьте действие **Open Website**.
2. Укажите ссылку вида `https://t.me/username`.
3. Замените `username` на имя без символа `@`.
4. При первом запуске разрешите Android открывать такие ссылки через Telegram.

Для доступных на телефоне ярлыков можно использовать **Launch Shortcut**. Набор ярлыков определяет само приложение, поэтому нужный чат присутствует не всегда.

Не настраивайте автоматическую отправку сообщений без подтверждения. Открытие чата безопаснее: пользователь сам проверит адресата и нажмёт кнопку отправки.

Документация: [Open Website](https://macrodroidforum.com/wiki/index.php/Action%3A_Open_Website_%2F_HTTP_GET), [Launch Shortcut](https://macrodroidforum.com/wiki/index.php/Action%3A_Launch_Shortcut), [официальные ссылки Telegram](https://core.telegram.org/api/links).

### Разные вибрации для разных событий

Действие **Vibrate** предлагает несколько рисунков вибрации. Можно назначить короткую вибрацию одному событию и длинную другому.

Пример:

- `Сообщение` — один короткий импульс;
- `Тренировка` — два длинных импульса;
- `Чтение` — без вибрации.

Для собственного рисунка чередуйте действия **Vibrate** и короткие **Wait Before Next Action**. Не делайте длинные циклы: они мешают и расходуют батарею.

Документация: [Vibrate](https://www.macrodroidforum.com/wiki/index.php/Action%3A_Vibrate).

### Полноэкранная карточка события

Действие **Display Custom Scene** позволяет собрать собственное окно: текст, картинку, кнопки, переключатели и индикатор.

Например, карточка события может содержать:

- название из переменной **«Текущее событие»**;
- кнопку **«Открыть игру»**;
- кнопку **«Открыть Telegram»**;
- кнопку **«Закрыть»**;
- картинку из файла, по ссылке или из Giphy.

Сначала сделайте простую сцену с одной кнопкой. Полноэкранная сцена может перекрыть текущее приложение, поэтому обязательно добавьте кнопку закрытия и проверьте её до постоянного использования.

Документация: [Display Custom Scene](https://macrodroidforum.com/wiki/index.php/Action%3A_Display_Custom_Scene).

### Ещё идеи

- Для `Тренировка`: увеличить громкость мультимедиа и открыть музыкальное приложение.
- Для `Чтение`: уменьшить яркость, включить режим «Не беспокоить» и открыть читалку.
- Для `Игра`: включить альбомную ориентацию, открыть игру и показать радужную анимацию.
- Для `Созвон`: открыть Telegram, приложение конференции или ссылку на встречу.
- Для `Перерыв`: произнести название события и запустить таймер.
- Для `Сон`: уменьшить яркость и включить режим «Не беспокоить».
- Для `Выход`: открыть карты или приложение такси.
- Для любого события: показать обычное уведомление, всплывающий пузырь или собственную сцену.

Изменение яркости, громкости, ориентации и режима «Не беспокоить» сохраняется после выполнения макроса. Добавьте отдельное действие или макрос для возврата прежних настроек. Сначала проверяйте новые цепочки через **«Проверить действия»**.

## Если не работает

### Меню не открывается

Разрешите отображение поверх других приложений. Затем перезапустите MacroDroid.

### Событие не сработало вовремя

Разрешите работу в фоне, отключите оптимизацию батареи и включите автозапуск. В MacroDroid откройте **Устранение неполадок** и выполните предложенные проверки.

### Пишет, что импорт не удался

Скопируйте сообщение заново и повторите импорт сразу после копирования. Нужен весь текст со служебным блоком от `MDUTC-BEGIN` до `MDUTC-END`.

### После импорта пропали старые макросы

`.mdr` является полным экспортом. Восстановите ранее созданную резервную копию MacroDroid.

## Безопасность

Shell-команды выполняются без root-прав. Импортируемый текст проверяется до передачи в shell. Конфигурация не содержит готового расписания, названий событий, токенов, паролей или других пользовательских данных.

Устанавливайте MacroDroid и обновления только из источников, которым доверяете.
